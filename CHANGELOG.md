# v0.5 Public Beta

- SDK-based campaign/resource addon conversion with dependencies, multipart input, repairs and explicit supplementation.
- Loader output with automatic addon registration, toggles, isolated preview identities, metadata and hardware-tested restart commands.
- Hash-checked Loader patching and clean rollback with mandatory permanent-installed-mod-deletion acknowledgement.
- Native Offline DLC, L4D1 survivor support, startup voice/music registration and working rotary materials.
- Actual missing chapter thumbnails imported at native size/format; mode menus omit campaigns with no maps for that mode.
- Optional metadata editor with required descriptive name, optional author/multiline description and Skip/Cancel.
- Fixed texture-only conversion's uninitialized MPEG report field.
- Bundled independent x360-convert 0.2.0, system/light/dark themes and installation examples.
- Portable source/Windows builds with clean settings, frozen paths and hidden startup checks.

Chocolate/Rust remains separate. Failed Float registration, HDR controls, PC-to-DLC page, xdReanims switches and single-ZIP campaigns are excluded from the public UI.
